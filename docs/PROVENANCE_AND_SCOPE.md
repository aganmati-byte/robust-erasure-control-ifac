# Provenance and scope

This GitHub-collaboration staging tree was assembled on 3 November 2026 from two prior archives:

1. `IFAC_2026_final_scientific_reproducibility_package.zip` -- source code, theorem-related scripts, standard results and original CPU notebook.
2. `IFAC_Alexander_Figure4_all_rates_SE_CI_2026-11-02.zip` -- revised five-pole simulation, raw costs, pointwise bootstrap intervals and updated Figure 4.

The Figure 4 recomputation script was modified only to resolve imports/CSV paths from the new repository layout. The data and plotted numerical points were copied from the existing verified bundle; they are not generated by an image model.

The live Overleaf manuscript is **not mirrored automatically**, and the dated manuscript snapshot is not a final submission file.

Do not conflate with the separate time-varying control project. Do not add its code or figures to this repository without a separate overlap and authorship review.

The `source_v3_unchanged` historical archive and exploratory draft notes remain in the user's local original ZIPs, not in this compact collaboration tree. This is a selective source/data release, not a complete conversational derivation transcript.
